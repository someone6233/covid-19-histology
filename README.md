# COVID-19: Inside the Lung — Version 1

This is a single-page interactive histology website for the Grade 7/8 assignment.

## Files

- `index.html` — page structure and content
- `style.css` — layout, typography, colors, responsive design
- `script.js` — interactions and progress logic
- `images/` — place final histology images here

## Important before submission

The tissue section currently uses schematic placeholders. Replace these with properly licensed/attributed histology images and add a small Sources/Credits section before submitting.

## Hosting

This project can be hosted directly with GitHub Pages:

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. In the repository, open Settings → Pages.
4. Select the branch containing the files and the `/ (root)` folder.
5. Save and wait for GitHub to publish the site.
6. Send the resulting `https://USERNAME.github.io/REPOSITORY/` link to your professor.
